# JustClub — Google Trends Search Query Test Matrix

**Market:** India (Country Code: `IN`)  
**Timeframe Recommended:** Past 12 Months & Past 5 Years  
**Categories:** All Categories or Sports / Computers & Electronics  
**Purpose:** Measure relative search interest and regional concentration across core cue-sports software, billing, timer, and operational queries in India without fabricating synthetic numbers.

---

## Group 1: Core Commercial Head Terms (India)

Test the relative demand between general software, management, and billing terminology:

```text
Comparison Terms:
1. snooker club software
2. snooker management software
3. snooker billing software
4. snooker software
5. club management software
```

### Strategic Evaluation Questions:
- Is `snooker billing software` trending higher than `snooker management software` in India? (Billing is often the primary entry-point pain query in Indian cash businesses).
- Which Indian states (Tamil Nadu, Karnataka, Telangana, Maharashtra, Delhi) generate the highest relative search interest?
